# 独家经销的分送认定、转单交货与清分

资料对应区域专供约定、大客户总部订单的分送行和对应该次销售的实际回执。所有组织、资料、金额和业务回执均为合成。

完整数据口径见[《渠道授权与交货交换记录》](交换记录.md)。输入使用 UTF-8 JSON，资料原件均为 UTF-8 文本。

环境使用 CPython 3.11 标准库，无需安装第三方依赖。下列命令核查交换材料的关联及格式。

```sh
python3 -m unittest discover -s tests -v
```

`channel_ops` 把交换记录落成可核查的认定：

| 模块 | 作用 |
| --- | --- |
| `channel_ops/model.py` | 合同、分送行、出库回执、转单申领与认定结果的数据结构 |
| `channel_ops/engine.py` | 授权归属、分送行可交货判断、仓班转单检查、交货核认、清分与可见性 |
| `channel_ops/report.py` | 按区域负责人、仓库、渠道财务、经销商与总部客户分别输出结果 |

关键口径：

- 认定依据是客户有权代表确认的**最终使用工厂与行政区**；开票地址、收货地址与中转点都不产生经销权。
- 排他合同按地区、产品系列与生效期限判定；已报备直供客户例外优先。
- 收货点只是中转时，按获认可的最终用途凭证判断适用经销权。
- 行政区调整后，原签认且未变的用途按合同过渡期处理；后来增加的分送地或数量重新审。
- 商业转单同意（客户 + 接方）不等于出库授权；原指令回执未知时不得向接方另发同货指令，确认未提货后方可停原指令再发。
- 已交付部分按真实使用地和交货当时批准的渠道核认，日后资格变化不改算给别家。
- 同一笔交货只产生一份渠道报酬；有记录的认领争议只暂缓争议金额，未受波及的行照常出账；违约补偿单独按最终核认区域、受损合同与争议结论办理。

```sh
python3 -m channel_ops.report
```

经销商视角只返回自己的授权、交货与报酬凭据；总部客户可在自己订单上分辨可继续提货、需另行同意或需核实。
